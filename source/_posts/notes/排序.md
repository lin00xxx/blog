## 1. 排序基础

### 1.1 定义

把一组记录按某个**关键字**的递增或递减顺序重新排列，使无序变有序。

### 1.2 四个评价指标

| 指标       | 含义                                     | 备注                         |
| ---------- | ---------------------------------------- | ---------------------------- |
| 时间复杂度 | 比较/移动次数随 n 的增长                 | 分最坏、平均、最好三种情况   |
| 空间复杂度 | 额外占用的内存                           | O(1) 即原地排序              |
| **稳定性** | 关键字相等的元素，排序后**相对顺序不变** | 见下                         |
| 适应性     | 对不同数据（近乎有序、范围小等）的表现   | 如插入排序对近乎有序数据极快 |

**稳定性为什么重要**：多级排序时需要。例如先按姓名排，再按成绩排；若成绩排序稳定，则同分者仍保持姓名顺序。

### 1.3 分类

```
排序
├─ 比较排序：靠元素两两比较决定顺序
│   冒泡、选择、插入、希尔、快速、归并、堆
│   （理论下界 Ω(n log n)，不可能更快）
└─ 非比较排序：利用数据本身的性质（范围、位数、分布）
    计数、桶、基数
    （条件满足时可达线性 O(n)）
```

### 1.4 按思想再归一次（帮助记忆）

| 思想      | 算法           | 一句话                   |
| --------- | -------------- | ------------------------ |
| 交换      | 冒泡、快速     | 通过交换逆序对消除无序   |
| 选择      | 选择、堆       | 每次选出最值放到最终位置 |
| 插入      | 插入、希尔     | 把新元素插进已有序部分   |
| 分治      | 归并、快速     | 拆小 → 解决 → 合并       |
| 计数/分配 | 计数、桶、基数 | 不比较，直接“定位”       |

## 2. 排序算法

### 2.1 冒泡排序 (Bubble Sort)

**思想**：反复比较**相邻**两元素，逆序就交换。每一趟都会把当前未排序部分的最大值“冒”到末尾。

**过程**（以 `9 8 5 4 2 0` 为例，课件实例）：

```
初始      9 8 5 4 2 0
第0趟后   8 5 4 2 0 | 9      ← 最大值 9 就位
第1趟后   5 4 2 0 | 8 9
第2趟后   4 2 0 | 5 8 9
第3趟后   2 0 | 4 5 8 9
第4趟后   0 | 2 4 5 8 9      ← 共 n-1 = 5 趟（此例每趟都有交换）
```

**循环边界（必背）**

- 外层：最多 **n-1 趟**，`j` 从 0 到 n-2。

- 内层：第 

  ```
  j
  ```

   趟比较 

  n-1-j 次

  ，

  ```
  i
  ```

   从 0 到 n-2-j，比较 

  ```
  a[i]
  ```

   与 

  ```
  a[i+1]
  ```

  。

  - 为什么递减：每趟末尾多一个已就位元素，不必再比。

**优化：提前终止**

设标志 `bexchange`：每趟开始前置 `false`；**发生交换就置 `true`**。一趟结束若仍为 `false`，说明已经有序，直接退出。

```cpp
void bubbleSort(int a[], int n) {
    bool bexchange = true;
    for (int j = 0; j < n - 1 && bexchange; j++) {   // 标志作为循环条件之一
        bexchange = false;
        for (int i = 0; i < n - 1 - j; i++) {
            if (a[i] > a[i + 1]) {                    // 严格大于 → 相等不交换 → 稳定
                swap(a[i], a[i + 1]);
                bexchange = true;
            }
        }
    }
}
```

| 时间（平均/最坏） | 时间（最好）                   | 空间 | 稳定性 |
| ----------------- | ------------------------------ | ---- | ------ |
| O(n²)             | O(n)（已有序，一趟扫描即退出） | O(1) | 稳定   |

> 注：课件 p13 的文字把 `bexchange` 的 true/false 写反了，以上述代码为准。

### 2.2 选择排序 (Selection Sort)

**思想**：把数组分成“已排序区（前）”和“未排序区（后）”。每趟在未排序区中**选出最小值**，与未排序区的第一个元素交换，已排序区扩大一格。

**过程**（`64 25 12 22 11`）：

```
第0趟：在全部中选最小 11，与 a[0] 交换   → 11 | 25 12 22 64
第1趟：在 [1..] 中选最小 12，与 a[1] 交换 → 11 12 | 25 22 64
第2趟：选 22，与 a[2] 交换                → 11 12 22 | 25 64
第3趟：选 25，已在原位                    → 11 12 22 25 64
```

**循环边界**

- 外层 `i`：0 到 n-2，共 n-1 趟。
- 内层 `j`：`i+1` 到 n-1，用 `k` 记录最小值下标。
- 每趟**只交换一次**：`a[i]` 与 `a[k]`。

```cpp
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int k = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[k]) k = j;
        if (k != i) swap(a[i], a[k]);
    }
}
```

**优化（课件 ☆）：一趟同时选最大和最小**，两端同时收缩，趟数减半。

```cpp
void selectionSort2(int a[], int n) {
    for (int l = 0, r = n - 1; l < r; l++, r--) {
        int mn = l, mx = l;
        for (int j = l; j <= r; j++) {
            if (a[j] < a[mn]) mn = j;
            if (a[j] > a[mx]) mx = j;
        }
        swap(a[l], a[mn]);
        if (mx == l) mx = mn;        // 坑：最大值原本在 l，已被换到 mn 处
        swap(a[r], a[mx]);
    }
}
```

**为什么不稳定**：`[5a, 5b, 2]` 第一趟把 2 与 `5a` 交换 → `[2, 5b, 5a]`，两个 5 的顺序反了。长距离交换是根源。

| 时间（三种情况）                         | 空间 | 稳定性     |
| ---------------------------------------- | ---- | ---------- |
| 都是 O(n²)（不管有序与否，比较次数固定） | O(1) | **不稳定** |

### 2.3 插入排序 (Insertion Sort)

**思想**：像整理扑克牌。左侧是已排好的手牌，每次从右边**抓一张新牌**，从后向前扫描，找到合适位置插进去。

**步骤**

1. 第 0 个元素视为已排序。
2. 取下一个元素 `key`，在已排序部分**从后往前**扫描。
3. 已排序元素 **> key** 就后移一位。
4. 直到遇到 **≤ key** 的元素（或越过开头），把 `key` 放到空位。
5. 重复直到结束。

**过程**（`5 2 4 6 1 3`）：

```
i=1 key=2   [5] → 5后移          → 2 5 | 4 6 1 3
i=2 key=4   5后移                → 2 4 5 | 6 1 3
i=3 key=6   无需移动             → 2 4 5 6 | 1 3
i=4 key=1   6 5 4 2 全后移       → 1 2 4 5 6 | 3
i=5 key=3   6 5 4 后移           → 1 2 3 4 5 6
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) {    // 严格大于 → 稳定
            a[j + 1] = a[j];              // 后移，不是交换，更省
            j--;
        }
        a[j + 1] = key;
    }
}
```

**特点**：数据越接近有序越快（最好 O(n)）。这一点是希尔排序和快排“小区间优化”的理论基础。

| 平均/最坏               | 最好           | 空间 | 稳定性 |
| ----------------------- | -------------- | ---- | ------ |
| O(n²)（最坏：完全逆序） | O(n)（已有序） | O(1) | 稳定   |

### 2.4 希尔排序 (Shell Sort)

**动机**：插入排序慢，是因为元素一次只能挪一格；但它在“基本有序”时很快。希尔的做法：**先让数据大步流星地基本有序，最后再用一次插入排序收尾**。

**思想**：取增量 `gap`，把所有**距离为 gap 的元素**归为一组，各组内部做插入排序（称“预排序”）。逐步缩小 gap，直到 `gap = 1`，此时就是一次普通插入排序，但数据已基本有序，代价很低。

- gap 大：元素跳得远，但不够精细；
- gap 小：精细，但移动慢。
- 常用序列：`gap = n/2, n/4, …, 1`；或课件的 `gap = gap/3 + 1`。**最后一轮必须是 1**。

**过程**（`49 38 65 97 76 13 27 49`，n=8）：

```
gap=4：分组 (0,4)(1,5)(2,6)(3,7)，组内排序
       49 13 27 49 76 38 65 97
gap=2：分组 偶下标{49,27,76,65}→{27,49,65,76}
           奇下标{13,49,38,97}→{13,38,49,97}
       27 13 49 38 65 49 76 97
gap=1：普通插入排序（已很接近有序）
       13 27 38 49 49 65 76 97
```

课件的“四层循环”写法（gap → 组号 → 组内元素 → 插入过程）和下面的写法本质相同，下面是常见的合并写法：

```cpp
void shellSort(int a[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {      // ① 外层：缩小增量
        for (int i = gap; i < n; i++) {             // ② 各组交替推进
            int key = a[i], j = i - gap;
            while (j >= 0 && a[j] > key) {          // ③ 组内插入，步长为 gap
                a[j + gap] = a[j];
                j -= gap;
            }
            a[j + gap] = key;
        }
    }
}
```

即把插入排序里的“步长 1”换成“步长 gap”。

**复杂度**：与增量序列有关，**没有完整的理论结论**。

- 最坏 O(n²)；平均约 O(n^1.3) ~ O(n^1.5)（实验统计，非理论证明）；
- 最好（已有序）接近 O(n)。
- 不稳定：相同元素可能被分在不同组，各自移动而打乱顺序。

> 注：课件 p28 把“时间复杂度”写成 O(nlogn)，与同页平均值矛盾，应以平均 O(n^1.3) 为准。

| 平均       | 最坏  | 空间 | 稳定性 |
| ---------- | ----- | ---- | ------ |
| ≈ O(n^1.3) | O(n²) | O(1) | 不稳定 |

### 2.5 快速排序 (Quick Sort)

**起源**：1960 年 C. A. R. Hoare 提出，是对冒泡排序的重大改进（冒泡每次只交换相邻元素，快排一次交换能跨越很远）。

**思想：分治**

1. 选一个**基准数** `key`；
2. **分区 (partition)**：把比 key 大的放右边，≤ key 的放左边，key 落在最终位置；
3. 对左右两个区间**递归**重复，直到区间只剩 ≤1 个元素。

关键：**一趟分区之后，key 已经在最终位置上**，不会再动。

#### 分区的双指针做法（课件主版本）

- `begin` 从左往右、`end` 从右往左，基准取 `a[left]`（下标记 `keyi`）。
- **先动 end**：找到 `<= key` 的停下；
- **再动 begin**：找到 `> key` 的停下；
- 若 `begin < end`：交换，继续；
- 相遇后：`swap(a[keyi], a[begin])`，key 落位，返回其下标。

> **为什么必须右边先走？** 相遇位置的值必须 ≤ key 才能与 key 交换。右边先走时，相遇点要么是 end 停下的 ≤key 元素，要么是 begin 追到的、已被换过去的 ≤key 元素。若左边先走，相遇点可能是 >key 的值，换到首位就错了。（基准取左端时的规则；取右端则反过来。）

```cpp
void quickSort(int a[], int left, int right) {
    if (left >= right) return;                 // 递归出口：长度 ≤ 1
    int begin = left, end = right, keyi = left;
    while (begin < end) {
        while (begin < end && a[end]   >  a[keyi]) end--;     // 右边找 <= key
        while (begin < end && a[begin] <= a[keyi]) begin++;   // 左边找 >  key
        swap(a[begin], a[end]);
    }
    swap(a[keyi], a[begin]);                   // key 归位
    keyi = begin;
    quickSort(a, left, keyi - 1);
    quickSort(a, keyi + 1, right);
}
// 调用：quickSort(a, 0, n - 1);
```

**一趟分区过程**（`49 38 65 97 76 13 27`，key=49）：

```
end 左移，27≤49 停；begin 右移，65>49 停 → 交换
     49 38 27 97 76 13 65
end 左移，13≤49 停；begin 右移，97>49 停 → 交换
     49 38 27 13 76 97 65
end 左移到 begin 位置（97、76 都 >49），相遇
swap(a[keyi], a[begin])：
     13 38 27 | 49 | 76 97 65       ← 49 归位
继续递归：[13 38 27] 与 [76 97 65]
```

#### 其他版本：挖坑法

先把 key 取出，留下一个“坑”，右边找小的填坑、左边找大的填坑，轮流进行，最后把 key 填入最后的坑。课件 p33 的图示即此过程。

```cpp
int partitionHole(int a[], int left, int right) {
    int key = a[left], hole = left;
    int begin = left, end = right;
    while (begin < end) {
        while (begin < end && a[end]   >  key) end--;
        a[hole] = a[end];   hole = end;        // 右边小的 → 填左坑，右边出现新坑
        while (begin < end && a[begin] <= key) begin++;
        a[hole] = a[begin]; hole = begin;      // 左边大的 → 填右坑
    }
    a[hole] = key;
    return hole;
}
void quickSort2(int a[], int left, int right) {
    if (left >= right) return;
    int p = partitionHole(a, left, right);
    quickSort2(a, left, p - 1);
    quickSort2(a, p + 1, right);
}
```

#### 优化一：三数取中

**问题**：数组已有序/逆序时，若基准恰好是最小/最大值，每次分区得到“空 + 几乎整个数组”，递归深度退化到 n，整体 **O(n²)**。

**做法**：比较 `a[left]`、`a[mid]`、`a[right]`，取**中间值**作基准，并把它换到 `left`，其余代码不变。

```cpp
int getMid(int a[], int l, int r) {
    int m = l + (r - l) / 2;
    if (a[l] < a[m]) {
        if (a[m] < a[r]) return m;
        else if (a[l] < a[r]) return r;
        else return l;
    } else {
        if (a[m] > a[r]) return m;
        else if (a[l] > a[r]) return r;
        else return l;
    }
}
// 在分区前加： swap(a[left], a[getMid(a, left, right)]);
```

随机选基准也能达到同样目的。

#### 优化二：小区间改插入排序

区间很小时，递归调用 + 栈帧开销大于收益，而插入排序对小数组很快。

```cpp
void quickSort3(int a[], int left, int right) {
    if (right - left + 1 < 10) {              // 阈值常取 10 左右
        insertionSort(a + left, right - left + 1);
        return;
    }
    swap(a[left], a[getMid(a, left, right)]);
    // ……后面同 quickSort 的分区与递归
}
```

#### 性能

| 情况 | 时间       | 原因                                        |
| ---- | ---------- | ------------------------------------------- |
| 最好 | O(n log n) | 每次均分，递归树高 log n，每层总计 n 次比较 |
| 平均 | O(n log n) | 随机数据                                    |
| 最坏 | O(n²)      | 基准总是极值，如有序数组 + 取首元素         |

- 空间：O(log n)（递归栈，最坏 O(n)，优化后基本不出现）
- 稳定性：**不稳定**（分区时的远距离交换会打乱相等元素）。需要稳定请用归并。

### 2.6 归并排序 (Merge Sort)

**思想：分治**——“先拆到不能再拆，再两两有序合并”。

1. **分解**：`mid = (left + right) / 2`，把区间一分为二；
2. **解决**：递归排序左半 `[left, mid]`、右半 `[mid+1, right]`；
3. **合并**：把两个**有序**的半区间合成一个有序区间（核心）。

递归出口：区间只有一个元素（本身有序）。

**图示**（`38 27 43 3 9 82 10`）：

```
                [38 27 43 3 9 82 10]
               /                    \
        [38 27 43 3]            [9 82 10]
        /        \               /      \
    [38 27]    [43 3]         [9 82]    [10]
     /  \       /  \           / \
   [38][27]  [43][3]         [9][82]
     \  /       \  /           \ /
   [27 38]    [3 43]         [9 82]    [10]
        \        /               \      /
        [3 27 38 43]            [9 10 82]
               \                    /
              [3 9 10 27 38 43 82]
```

**合并步骤（升序）**

1. 两个指针 `i`、`j` 分别指向左、右半区起点；
2. 比较 `a[i]` 与 `a[j]`，**较小者**先放入临时数组 `tmp`，对应指针后移；
3. 一直到某一半取完；
4. 把另一半**剩余元素**直接接到 `tmp` 末尾；
5. 把 `tmp` 对应区段**拷回**原数组。

**实现要点**：合并需要与原数组等大的临时数组。**主函数一次性申请**，子函数全程复用，避免反复申请/释放的开销。

```cpp
void mergeSort(int a[], int tmp[], int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(a, tmp, left, mid);
    mergeSort(a, tmp, mid + 1, right);

    int i = left, j = mid + 1, k = left;
    while (i <= mid && j <= right)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];   // <= ：相等取左边 → 稳定
    while (i <= mid)   tmp[k++] = a[i++];              // 左边剩余
    while (j <= right) tmp[k++] = a[j++];              // 右边剩余
    for (k = left; k <= right; k++) a[k] = tmp[k];     // 拷回
}

void mergeSort(int a[], int n) {                       // 主调函数：只管申请/释放
    int* tmp = new int[n];
    mergeSort(a, tmp, 0, n - 1);
    delete[] tmp;
}
```

**复杂度直觉**：递归树共 log n 层，每层合并总共处理 n 个元素 → O(n log n)。输入是什么样都不变，所以最好/最坏/平均**全是** O(n log n)。

| 时间                       | 空间             | 稳定性 |
| -------------------------- | ---------------- | ------ |
| O(n log n)（三种情况相同） | O(n)（临时数组） | 稳定   |

**应用**：数据量大到装不进内存（外部排序）时，可以分文件各自排好序，再做合并。

### 2.7 计数排序 (Counting Sort)

**非比较排序**。不比较元素大小，而是**统计每个值出现几次**，再据此还原有序序列。

**适用条件**：数据是**范围确定且不大**的整数（成绩、年龄等）。

**步骤**

1. 确定数据范围（求 `min`、`max`，范围 `k = max - min + 1`）；
2. 初始化长度为 `k` 的计数数组，全 0；
3. 遍历原数组，`cnt[a[i] - min]++`；
4. 按值从小到大输出：值 `v` 输出 `cnt[v]` 次；
5. 释放计数数组。

**过程**（`2 5 3 0 2 3 0 3`，min=0，max=5）：

```
cnt 下标: 0 1 2 3 4 5
cnt 值  : 2 0 2 3 0 1
输出    : 0 0 2 2 3 3 3 5
void countingSort(int a[], int n) {
    int mn = *min_element(a, a + n), mx = *max_element(a, a + n);
    vector<int> cnt(mx - mn + 1, 0);
    for (int i = 0; i < n; i++) cnt[a[i] - mn]++;
    int idx = 0;
    for (int v = 0; v < (int)cnt.size(); v++)
        for (int c = 0; c < cnt[v]; c++) a[idx++] = v + mn;
}
```

**稳定版（用于对象排序，是基数排序的基础）**：对 `cnt` 做前缀和，`cnt[v]` 变成“值 ≤ v 的元素个数”，即 v 的**最后一个位置+1**；然后从后往前扫描原数组放位置。

```cpp
vector<int> countingSortStable(const vector<int>& a, int mn, int mx) {
    vector<int> cnt(mx - mn + 1, 0), out(a.size());
    for (int x : a) cnt[x - mn]++;
    for (size_t v = 1; v < cnt.size(); v++) cnt[v] += cnt[v - 1];   // 前缀和
    for (int i = (int)a.size() - 1; i >= 0; i--)                     // 倒序 → 稳定
        out[--cnt[a[i] - mn]] = a[i];
    return out;
}
```

| 时间     | 空间 | 稳定性               |
| -------- | ---- | -------------------- |
| O(n + k) | O(k) | 稳定（用前缀和版本） |

> 注意：k 远大于 n 时（如 n=10，值域 10⁹）反而更慢、更耗内存，别用。

### 2.8 补充：堆排序 / 桶排序 / 基数排序

课件对比表中出现，但未展开。这里给出核心逻辑。

**堆排序**：用**大顶堆**（父 ≥ 子）。

1. 建堆：从最后一个非叶子结点 `n/2-1` 往前依次“下沉”；
2. 重复：堆顶（最大值）与堆尾交换，堆大小减 1，对堆顶下沉。

```cpp
void siftDown(int a[], int n, int i) {
    while (true) {
        int l = 2 * i + 1, r = l + 1, m = i;
        if (l < n && a[l] > a[m]) m = l;
        if (r < n && a[r] > a[m]) m = r;
        if (m == i) break;
        swap(a[i], a[m]);
        i = m;
    }
}
void heapSort(int a[], int n) {
    for (int i = n / 2 - 1; i >= 0; i--) siftDown(a, n, i);   // 建堆 O(n)
    for (int e = n - 1; e > 0; e--) {
        swap(a[0], a[e]);                                      // 最大值就位
        siftDown(a, e, 0);
    }
}
```

时间 O(n log n)（三种情况相同），空间 O(1)，**不稳定**。

**桶排序**：把值域分成若干区间（桶），元素按值分到各桶，桶内各自排序，再按桶顺序拼接。数据**均匀分布**时接近 O(n)；全挤进一个桶则退化为桶内排序的复杂度（表中最坏 O(n²)）。

**基数排序（LSD）**：按位数从低位到高位，依次对每一位做**稳定的**计数排序。正因为每轮稳定，高位排序不会破坏低位已排好的顺序。

```cpp
void radixSort(vector<int>& a) {            // 仅限非负整数
    if (a.empty()) return;
    int mx = *max_element(a.begin(), a.end());
    vector<int> out(a.size());
    for (long long exp = 1; mx / exp > 0; exp *= 10) {
        int cnt[10] = {0};
        for (int x : a) cnt[x / exp % 10]++;
        for (int d = 1; d < 10; d++) cnt[d] += cnt[d - 1];
        for (int i = (int)a.size() - 1; i >= 0; i--)
            out[--cnt[a[i] / exp % 10]] = a[i];
        a = out;
    }
}
```

时间 O(d·(n+k))，d 为位数，k 为基数（这里 10）。

### 3.1 性能对比

| 算法 | 平均       | 最坏       | 最好       | 空间     | 稳定性         |

| 冒泡 | O(n²)      | O(n²)      | O(n)       | O(1)     | 稳定           |

| 快速 | O(n log n) | O(n²)      | O(n log n) | O(log n) | **不稳定**     |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n)     | 稳定           |
| 堆   | O(n log n) | O(n log n) | O(n log n) | O(1)     | **不稳定**     |
| 计数 | O(n+k)     | O(n+k)     | O(n+k)     | O(k)     | 稳定           |

**记忆口诀**：不稳定的四个——**选、希、快、堆**（“选希快堆”）。其余基本稳定。

### 3.2 选型建议

| 场景                                 | 推荐                              |
| ------------------------------------ | --------------------------------- |
| 数据量很小（几十个以内） / 近乎有序  | 插入排序                          |
| 一般大规模通用排序                   | 快速排序（带优化）/ 标准库 `sort` |
| 需要稳定性，不在乎额外空间           | 归并排序（`stable_sort`）         |
| 严格限制空间 + 要保证最坏 O(n log n) | 堆排序                            |
| 整数、值域小（成绩、年龄）           | 计数排序                          |
| 数据均匀分布                         | 桶排序                            |
| 整数位数少、范围大                   | 基数排序                          |
| 只需前 k 大/小或反复取最值           | 堆（优先队列）                    |
| 数据超出内存                         | 归并思想（外部排序）              |

## 4. qsort 与 sort

实际做题基本直接用库函数。

### 4.1 `qsort`（C/C++，`<stdlib.h>`）

```c
void qsort(void *base, size_t num, size_t width,
           int (*compare)(const void *, const void *));
```

| 参数      | 含义                                                         |
| --------- | ------------------------------------------------------------ |
| `base`    | 数组首地址（`void*`）                                        |
| `num`     | 元素个数                                                     |
| `width`   | 每个元素的字节数，常写 `sizeof(a[0])`                        |
| `compare` | 自定义比较函数，参数是 `void*`，**必须先强转为元素类型指针** |

**compare 的返回值约定**：`<0` 表示 elem1 排前面；`>0` 表示 elem1 排后面；`0` 表示相等。

**① 基本类型**

```cpp
int cmpInt(const void *e1, const void *e2) {
    return *(int *)e1 - *(int *)e2;       // 升序；降序则对调
}
int num[100];
qsort(num, 100, sizeof(num[0]), cmpInt);
```

**② 结构体一级排序**

```cpp
struct student { char name[20]; int age; double score; };

int cmpAge(const void *e1, const void *e2) {
    return ((student *)e1)->age - ((student *)e2)->age;
}
qsort(s, 10, sizeof(s[0]), cmpAge);
```

**③ 结构体二级排序**（age 升序，相同再按 score 升序）

```cpp
int cmp2(const void *e1, const void *e2) {
    student *p1 = (student *)e1, *p2 = (student *)e2;
    if (p1->age != p2->age) return p1->age - p2->age;
    if (p1->score < p2->score) return -1;           // double 不能直接相减后当 int 返回
    if (p1->score > p2->score) return 1;
    return 0;
}
```

> **两个常见坑**
>
> 1. **相减溢出**：`a - b` 在值很大时可能溢出（如 `INT_MAX - (-1)`）。保险写法：`return (a > b) - (a < b);`
> 2. **浮点相减**：`0.3` 的差被转为 `int` 会变成 0，被判为“相等”。浮点必须用 `<` `>` 比较。
>
> 课件 p57 中 `return p1->score - p2->score;` 即有此隐患。

### 4.2 `sort`（C++，`<algorithm>`）

```cpp
sort(first, last, comp);    // 区间 [first, last)，左闭右开，平均 O(n log n)
```

- `first`：起始地址/迭代器；
- `last`：**结束位置的下一个**（数组即 `arr + n`）；
- `comp`：可选，缺省升序。

**默认与降序**

```cpp
sort(arr, arr + n);                              // 数组升序
sort(vec.begin(), vec.end());                    // vector 升序
sort(vec.begin(), vec.end(), greater<int>());    // 降序
```

**自定义规则的四种写法**

```cpp
// ① 比较函数
bool cmp(int a, int b) { return a % 10 > b % 10; }       // 按个位降序
sort(arr, arr + n, cmp);

// ② Lambda
sort(vec.begin(), vec.end(), [](int a, int b) { return abs(a) < abs(b); });

// ③ 函数对象（多关键字）
struct MultiKeySort {
    bool operator()(const Data& a, const Data& b) const {
        if (a.x != b.x) return a.x > b.x;    // 主键 x 降序
        if (a.y != b.y) return a.y < b.y;    // 次键 y 升序
        return a.z > b.z;                    // 第三键 z 降序
    }
};
sort(data.begin(), data.end(), MultiKeySort());

// ④ 结构体重载 <
struct Student {
    string name; int score;
    bool operator<(const Student &b) const { return score > b.score; }   // 成绩降序
};
sort(students, students + n);                // 不用再传 cmp
```

**结构体二级排序**

```cpp
bool cmp(const Student &a, const Student &b) {
    if (a.score != b.score) return a.score > b.score;   // 成绩降序
    return a.name < b.name;                             // 同分按姓名升序
}
sort(students, students + n, cmp);
```

> **比较函数的铁律：必须是“严格弱序”** `cmp(a, a)` 必须返回 `false`。所以写 `<` 或 `>`，**不要写 `<=` / `>=`**，否则相等元素出现时可能死循环、越界、崩溃（Runtime Error），这是最典型的坑。

### 4.3 对比

|             | `qsort`                | `sort`                           |
| ----------- | ---------------------- | -------------------------------- |
| 语言/头文件 | C，`<stdlib.h>`        | C++，`<algorithm>`               |
| 比较函数    | 返回负/零/正的 `int`   | 返回 `bool`（a 是否应排在 b 前） |
| 类型        | `void*` 强转，易错     | 模板，类型安全                   |
| 速度        | 通过函数指针调用，较慢 | 可内联，通常更快                 |
| 稳定性      | 不保证                 | 不保证（要稳定用 `stable_sort`） |

## 5. 排序例题

### 5.1 快乐的蠕虫 The Happy Worm（1352）

**题意**：m×n 网格，k 块石头。蠕虫睡觉时横着或竖着，**尽可能伸展**，不能越界、不能压石头，**长度至少 2**。问有多少个不同的睡觉位置。数据范围 m, n, k ≤ 200000。

**理解题意（最关键）**

- “尽可能伸展” → 一段连续空格只对应**一个**位置，不论蠕虫头在哪（第 1 列有 4 个连续空格，只算 1 个，不算 3 个）。
- “长度 ≥ 2” → 只计算长度 ≥ 2 的**极大连续空段**。
- 所以问题 = **统计所有行、列中长度 ≥ 2 的极大空段数量**。

**为什么不能建二维数组**：m×n 最大 4×10¹⁰，内存放不下，二重循环扫描也必然超时。

**解法：只存石头，排序后扫描相邻石头**

1. 在网格四周“添加”一圈虚拟石头（第 0 行、第 m+1 行、第 0 列、第 n+1 列，共 2(m+n) 块，角落不用），这样**每一段空格两端都有石头**，不用特判边界；
2. **按行排序**：先按 x（行）升序，x 相同再按 y（列）升序。排序后，同一行的石头依次相邻。若相邻两块 x 相同、且 `y 差 > 2`，则中间有 ≥ 2 个空格 → 一个横向位置；
3. **按列排序**：先按 y 升序，y 相同再按 x 升序；同理，相邻两块 y 相同、`x 差 > 2` → 一个纵向位置。

> 为什么是 “差 > 2”：两块石头坐标差为 d，中间空格数是 d−1；要求空格数 ≥ 2，即 d ≥ 3，d > 2。

**样例核对（5×5，6 块石头）**：横向 5 行各 1 段 = 5；纵向第 1、2、4、5 列各 1 段 = 4（第 3 列没有）；合计 **9** ✓。若去掉 (4,2) 的石头，第 4 行 (4,3) 左边也成一段，变 10。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct P { int x, y; };
bool cmpRow(const P &a, const P &b) { return a.x != b.x ? a.x < b.x : a.y < b.y; }
bool cmpCol(const P &a, const P &b) { return a.y != b.y ? a.y < b.y : a.x < b.x; }

int main() {
    int t;
    scanf("%d", &t);
    while (t--) {
        int m, n, k;
        scanf("%d%d%d", &m, &n, &k);
        vector<P> s;
        s.reserve(k + 2 * (m + n));
        for (int i = 0; i < k; i++) {
            int x, y; scanf("%d%d", &x, &y);
            s.push_back({x, y});
        }
        for (int j = 1; j <= n; j++) { s.push_back({0, j}); s.push_back({m + 1, j}); }
        for (int i = 1; i <= m; i++) { s.push_back({i, 0}); s.push_back({i, n + 1}); }

        int ans = 0;
        sort(s.begin(), s.end(), cmpRow);                       // 横向
        for (size_t i = 1; i < s.size(); i++)
            if (s[i].x == s[i - 1].x && s[i].y - s[i - 1].y > 2) ans++;

        sort(s.begin(), s.end(), cmpCol);                       // 纵向
        for (size_t i = 1; i < s.size(); i++)
            if (s[i].y == s[i - 1].y && s[i].x - s[i - 1].x > 2) ans++;

        printf("%d\n", ans);
    }
    return 0;
}
```

**复杂度**：O((k+m+n) log(k+m+n))，只存石头，内存 O(k+m+n)。

**从这题带走的思想**：数据太大不能存全图时，**只存“关键点”，用排序把相关的点聚到一起，再线性扫描相邻项**。

### 5.2 单词重组 Word Amalgamation（1353）

**题意**：给定一部字典（1~100 个单词，每个 ≤6 个小写字母，以 `XXXXXX` 结束），再给若干个被打乱字母的单词（以 `XXXXXX` 结束）。对每个乱序词，按字典序输出字典中所有能由它**重排字母**得到的单词；没有则输出 `NOT A VALID WORD`；每组结果后输出一行 `******`。

**核心逻辑：两次排序**

1. **字母排序 → 判断“能否重排成”** 两个单词能互相重排，当且仅当它们**字母排序后完全相同**。 例：`trap`、`tarp`、`part` 排序后都是 `aprt`。 所以对字典里每个单词预先算好“签名”（字母排序后的串），对每个乱序词也算签名，**比较一次字符串即可**，不必逐一尝试全排列。
2. **字典排序 → 控制输出顺序** 题目要求按字母序输出，而不是按字典中出现的顺序。所以先把字典单词**按字典序排序**，查找时从前往后扫，命中的自然就是有序的。

**样例推演**：字典排序后 `course earn first … part pepper refund score tarp trap work`；乱序词 `aptr` 签名 `aprt`，命中 `part, tarp, trap`（按字典序）。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<string> dict, sig;
    string w;
    while (cin >> w && w != "XXXXXX") dict.push_back(w);
    sort(dict.begin(), dict.end());                 // ② 字典序，保证输出有序
    for (auto &d : dict) {
        string t = d;
        sort(t.begin(), t.end());                   // ① 字母排序 → 签名
        sig.push_back(t);
    }
    while (cin >> w && w != "XXXXXX") {
        string key = w;
        sort(key.begin(), key.end());
        bool found = false;
        for (size_t i = 0; i < dict.size(); i++)
            if (sig[i] == key) { cout << dict[i] << "\n"; found = true; }
        if (!found) cout << "NOT A VALID WORD\n";
        cout << "******\n";
    }
    return 0;
}
```

> 注：课件 p68 的“样例输入/输出”是误贴的蠕虫题数据，真正的样例在 p69。

**从这题带走的思想**：判断“字母构成相同”用**排序后比较**（规范化）；“输出有序”用**预先排序**。一道题里排序可以有两个不同的用途。

## 6. 易错点与复习清单

### 6.1 易错点

| 点                | 说明                                                        |
| ----------------- | ----------------------------------------------------------- |
| 冒泡内层边界      | `i < n-1-j`，否则越界或多比较                               |
| 选择排序交换次数  | 每趟只交换一次；双向优化时注意 `mx == l` 的特例             |
| 插入排序          | 用**后移**而不是反复交换；条件写 `a[j] > key`（严格）才稳定 |
| 希尔最后一轮      | `gap` 必须以 1 结束                                         |
| 快排指针顺序      | 基准取左端 → **右指针先走**                                 |
| 快排的 `<=` / `>` | 不写等号可能死循环、递归不收敛                              |
| 快排退化          | 有序数据 + 取首元素 = O(n²)，用三数取中/随机                |
| 归并合并          | 比较用 `<=` 才稳定；别忘了处理剩余元素与拷回                |
| 计数排序          | 值域过大不适用；有负数要减去最小值做偏移                    |
| `qsort` 比较函数  | 相减可能溢出；`double` 不能相减后返回 `int`                 |
| `sort` 比较函数   | 不要用 `<=`/`>=`，否则可能 RE                               |
| `sort` 区间       | `[first, last)`，`last` 是末尾的**下一个**位置              |
