# 数据结构笔记：线性表（顺序表 / 链表 / 多项式 / 归并）

> 对应题目：PTA 6-1、6-2、7-1、7-2（浙江大学 数据结构） 核心主题：**线性表的两种存储方式** + **在线性表上做运算**

------

## 0. 先搞懂：线性表是什么

**线性表**：一串元素，有先后顺序，除首尾外每个元素都有唯一前驱和唯一后继。

两种存储方式：

|             | 顺序存储（顺序表）     | 链式存储（链表）           |
| ----------- | ---------------------- | -------------------------- |
| 本质        | 一段**连续**内存，数组 | **离散**结点，靠指针串起来 |
| 访问第 i 个 | O(1)，直接下标         | O(n)，只能从头走           |
| 插入/删除   | O(n)，要挪动元素       | 找到位置后 O(1) 改指针     |
| 容量        | 固定上限（MAXSIZE）    | 动态，用多少申请多少       |
| 对应题目    | 6-1                    | 6-2、7-2                   |

四道题的知识点对应：

| 题号 | 考点                                         |
| ---- | -------------------------------------------- |
| 6-1  | 顺序表的增删查、判满、位置合法性             |
| 6-2  | 带头结点单链表的增删查、找前驱、指针操作     |
| 7-1  | 多项式的表示（用数组下标当指数）、乘法与加法 |
| 7-2  | 两个有序链表的**归并**（合并）               |

------

## 1. 题 6-1 顺序表操作集

### 1.1 题目

实现顺序表的四个函数：

```c
List MakeEmpty();
Position Find( List L, ElementType X );
bool Insert( List L, ElementType X, Position P );
bool Delete( List L, Position P );
```

结构定义：

```c
typedef int Position;
typedef struct LNode *List;
struct LNode {
    ElementType Data[MAXSIZE];
    Position Last;   /* 保存线性表中最后一个元素的位置 */
};
```

函数要求：

- `MakeEmpty`：创建并返回空表。

- `Find`：返回 X 的位置，找不到返回 `ERROR`（-1）。

- ```
  Insert
  ```

  ：把 X 插到位置 P。

  - 空间已满 → 打印 `FULL`，返回 false
  - P 非法 → 打印 `ILLEGAL POSITION`，返回 false

- `Delete`：删除位置 P 的元素。P 非法 → 打印 `POSITION P EMPTY`（P 是参数值），返回 false。

样例：

```
输入：
6
1 2 3 4 5 6
3
6 5 1
2
-1 6

输出：
FULL Insertion Error: 6 is not in.
Finding Error: 6 is not in.
5 is at position 0.
1 is at position 4.
POSITION -1 EMPTY Deletion Error.
FULL Insertion Error: 0 is not in.
POSITION 6 EMPTY Deletion Error.
FULL Insertion Error: 0 is not in.
```

### 1.2 关键概念

**`Last` 是什么**：最后一个元素的**下标**，不是元素个数。

| 状态            | Last 的值           |
| --------------- | ------------------- |
| 空表            | `-1`                |
| 1 个元素        | `0`                 |
| n 个元素        | `n-1`               |
| 满（MAXSIZE=5） | `4`，即 `MAXSIZE-1` |

**合法位置范围**

- 插入：`0 ~ Last+1`（可以插在最后一个元素后面，即"尾插"）
- 删除：`0 ~ Last`（必须有元素才能删）

**判断顺序**：先判满，再判位置。样例中表满且 P 也非法时，输出的是 `FULL` 而不是 `ILLEGAL POSITION`。

### 1.3 代码

```c
List MakeEmpty()
{
    List L = (List)malloc(sizeof(struct LNode));
    L->Last = -1;                 // 空表：Last = -1
    return L;
}

Position Find( List L, ElementType X )
{
    int i;
    for (i = 0; i <= L->Last; i++)   // 注意是 <= Last
        if (L->Data[i] == X) return i;
    return ERROR;
}

bool Insert( List L, ElementType X, Position P )
{
    int i;
    if (L->Last == MAXSIZE - 1) {            // 1. 先判满
        printf("FULL");
        return false;
    }
    if (P < 0 || P > L->Last + 1) {          // 2. 再判位置
        printf("ILLEGAL POSITION");
        return false;
    }
    for (i = L->Last; i >= P; i--)           // 3. 从后往前挪
        L->Data[i + 1] = L->Data[i];
    L->Data[P] = X;
    L->Last++;
    return true;
}

bool Delete( List L, Position P )
{
    int i;
    if (P < 0 || P > L->Last) {
        printf("POSITION %d EMPTY", P);
        return false;
    }
    for (i = P; i < L->Last; i++)            // 从前往后挪
        L->Data[i] = L->Data[i + 1];
    L->Last--;
    return true;
}
```

### 1.4 过程图解

在 `[1,2,3]`（Last=2）的位置 1 插入 9：

```
下标:   0  1  2  3
原:    [1][2][3][ ]
从后往前挪 (i=2 → 1):
       [1][2][3][3]     Data[3]=Data[2]
       [1][2][2][3]     Data[2]=Data[1]
放入:  [1][9][2][3]     Data[1]=9,  Last=3
```

**为什么插入必须从后往前挪？** 从前往后会把后面的元素覆盖掉，数据丢失。 **为什么删除要从前往后挪？** 同理，反过来。

### 1.5 易错点

1. `Last` 初始化成 0 而不是 -1 → 空表被当成有 1 个元素。
2. 判满写成 `Last == MAXSIZE` → 数组越界。
3. 判满和判位置顺序写反。
4. 循环写成 `i < Last` → 漏掉最后一个元素。
5. `printf` **不要**加 `\n`：main 里的错误提示是 `" Insertion Error: ..."`（前面带空格），样例输出里 `FULL Insertion Error` 就是接在同一行的。

### 1.6 自测与样例不一致的说明

自测页显示"评测代码与题面所示代码存在区别，自测结果仅供参考"。当时自测输出 6 个元素都插入成功，说明自测环境的 `MAXSIZE` 不是 5。代码逻辑与 `MAXSIZE` 无关，**以正式提交判题结果为准**。

### 1.7 复杂度

| 操作            | 时间             |
| --------------- | ---------------- |
| Find            | O(n)             |
| Insert / Delete | O(n)（要挪元素） |
| 取第 i 个       | O(1)             |

## 2. 题 6-2 带头结点的链式表操作集

### 2.1 题目

结构：

```c
typedef struct LNode *PtrToLNode;
struct LNode {
    ElementType Data;
    PtrToLNode Next;
};
typedef PtrToLNode Position;
typedef PtrToLNode List;
```

函数要求：

- `MakeEmpty`：创建并返回空表（带头结点）。
- `Find`：返回 X 所在**结点指针**，找不到返回 `ERROR`。
- `Insert`：把 X 插在 P 指向结点**之前**。P 非法 → 打印 `Wrong Position for Insertion`，返回 false。
- `Delete`：删除 P 指向的结点。P 非法 → 打印 `Wrong Position for Deletion`，返回 false。

样例：

```
输入：
6
12 2 4 87 10 2
4
2 12 87 5

输出：
2 is found and deleted.
12 is found and deleted.
87 is found and deleted.
Finding Error: 5 is not in.
5 is inserted as the last element.
Wrong Position for Insertion
Wrong Position for Deletion
10 4 2 5
```

### 2.2 关键概念

**头结点**：一个不存数据的"哨兵"结点，`L` 永远指向它，真正的第一个元素是 `L->Next`。

```
L → [头结点] → [12] → [2] → [4] → NULL
      不存数据
```

好处：插入/删除第一个元素时，不用特殊处理"头指针要改"，所有位置的操作逻辑统一（因为每个元素都有前驱，第一个元素的前驱是头结点）。

**Position 在这里是指针**，不是下标（和 6-1 不一样）。

**`NULL` 在 Insert 里有特殊含义**：`Insert(L, X, NULL)` 表示插在末尾（"在 NULL 之前" = 最后一个结点之后）。

### 2.3 核心技巧：找前驱

单链表只能往后走，不能往回走。要在 P 之前插入、或删除 P，必须先找到 **P 的前驱** `pre`（满足 `pre->Next == P`）：

```c
Position pre = L;
while (pre && pre->Next != P)
    pre = pre->Next;
```

循环结束有两种情况：

| 结果          | 含义                                     |
| ------------- | ---------------------------------------- |
| `pre != NULL` | 找到了，`pre->Next == P`                 |
| `pre == NULL` | 整条链走完都没找到 → P 不在链表里 → 非法 |

**P 为 NULL 时**：循环会停在尾结点（尾结点的 `Next` 正好等于 NULL），`pre` 非空 → 对 Insert 来说就是合法的尾插。

### 2.4 代码

```c
List MakeEmpty()
{
    List L = (List)malloc(sizeof(struct LNode));
    L->Next = NULL;                    // 空表：头结点的 Next 为空
    return L;
}

Position Find( List L, ElementType X )
{
    Position p = L->Next;              // 从第一个真实结点开始
    while (p && p->Data != X)
        p = p->Next;
    if (p) return p;
    return ERROR;
}

bool Insert( List L, ElementType X, Position P )
{
    Position pre = L, tmp;
    while (pre && pre->Next != P)      // 找 P 的前驱
        pre = pre->Next;
    if (!pre) {                        // P 不在链表中
        printf("Wrong Position for Insertion\n");
        return false;
    }
    tmp = (Position)malloc(sizeof(struct LNode));
    tmp->Data = X;
    tmp->Next = P;                     // 新结点指向 P
    pre->Next = tmp;                   // 前驱指向新结点
    return true;
}

bool Delete( List L, Position P )
{
    Position pre = L;
    while (pre && pre->Next != P)
        pre = pre->Next;
    if (!pre || !P) {                  // 不在链表中，或 P 为 NULL
        printf("Wrong Position for Deletion\n");
        return false;
    }
    pre->Next = P->Next;               // 跳过 P
    free(P);                           // 释放内存
    return true;
}
```

### 2.5 过程图解

在 `[A]→[C]` 中 C 之前插入 B（P 指向 C）：

```
pre=A, P=C
       A ──→ C
新结点 tmp=B：
  1) tmp->Next = P        B ──→ C
  2) pre->Next = tmp      A ──→ B ──→ C
```

**两步顺序不能反**：如果先 `pre->Next = tmp`，再 `tmp->Next = P`，这样虽然这里也没问题，但在"用 `pre->Next` 找后继"的写法里容易丢链，养成"先接后面、再接前面"的习惯。

删除 B：

```
A ──→ B ──→ C
pre=A, P=B
pre->Next = P->Next    A ──→ C       B 被跳过
free(P)                B 的内存归还
```

### 2.5.1 样例追踪

样例里每次都 `Insert(L, X, L->Next)`，即**头插**，所以插入 12 2 4 87 10 2 后链表是：

```
L → 2 → 10 → 87 → 4 → 2 → 12
```

删除 2（找到第一个 2）→ 12 → 87，剩 `10 4 2`；找 5 失败；最后尾插 5 → `10 4 2 5`。

### 2.6 易错点

1. **Delete 必须判 `!P`**：P 为 NULL 时 `pre` 会停在尾结点（`pre->Next == NULL == P`），`pre` 非空，若不额外判断就会执行 `P->Next` → **空指针解引用，段错误**。 Insert 则相反：NULL 是合法的尾插位置，不能判。
2. 忘记 `\n`：这题 main 里没有换行，错误提示必须自己加 `\n`。（初版就是这里"格式错误"。）
3. `Find` 从 `L->Next` 开始，不要从 `L` 开始，头结点不存数据。
4. 删除后忘记 `free`（不影响结果，但是良好习惯；注意 free 后不能再用 P）。
5. 循环条件 `pre && pre->Next != P`：**`pre` 的判断必须在前**，利用 `&&` 短路，避免 `pre` 为 NULL 时访问 `pre->Next`。

### 2.7 复杂度

| 操作            | 时间                            |
| --------------- | ------------------------------- |
| Find            | O(n)                            |
| Insert / Delete | O(n)（找前驱）；已知前驱时 O(1) |

## 3. 题 7-1 一元多项式的乘法与加法

### 3.1 题目

输入两个多项式（先给项数，再按指数递降给出"系数 指数"），输出乘积和以及和，均按指数递降，数字间空格分隔，**结尾无多余空格**，零多项式输出 `0 0`。

```
输入：
4 3 4 -5 2  6 1  -2 0
3 5 20  -7 4  3 1

输出：
15 24 -25 22 30 21 -10 20 -21 8 35 6 -33 5 14 4 -15 3 18 2 -6 1
5 20 -4 4 -5 2 9 1 -2 0
```

第一个多项式：3x⁴ − 5x² + 6x − 2；第二个：5x²⁰ − 7x⁴ + 3x。

### 3.2 思路：用数组下标表示指数

多项式的每一项是（系数，指数）。指数范围有限（0~1000），所以用**数组下标 = 指数，数组元素 = 系数**：

```
a[4] = 3, a[2] = -5, a[1] = 6, a[0] = -2
```

这种"以值作下标"的思想，本质是**直接寻址 / 桶**，和后面学的哈希表同源。

- **加法**：同下标相加。`add[i] = a[i] + b[i]`
- **乘法**：(c₁xᵉ¹)(c₂xᵉ²) = c₁c₂ x^(e₁+e₂)，所以 `mul[i+j] += a[i]*b[j]`。 乘积最高指数 1000+1000=2000，数组开 4001 足够。
- **合并同类项**自动完成：同指数累加到同一个下标。

### 3.3 输出处理

- 从高指数往低遍历，**系数为 0 的项跳过**（例如某些项相加抵消）。
- 用 `first` 标志控制空格：第一项前不打印空格，之后每项前先打印一个空格 → 结尾自然无多余空格。
- 若一项都没输出（`first` 仍为 1）→ 零多项式 → 打印 `0 0`。

### 3.4 代码

```c
#include <stdio.h>
#include <string.h>

#define OFF 1000
#define SZ 4001

int a[SZ], b[SZ], mul[SZ], add[SZ];

void print(int *c, int lo, int hi)
{
    int i, first = 1;
    for (i = hi; i >= lo; i--) {
        if (c[i]) {
            if (!first) printf(" ");
            printf("%d %d", c[i], i);
            first = 0;
        }
    }
    if (first) printf("0 0");
    printf("\n");
}

int main()
{
    int n, m, i, j, c, e;
    scanf("%d", &n);
    for (i = 0; i < n; i++) { scanf("%d %d", &c, &e); a[e] += c; }
    scanf("%d", &m);
    for (i = 0; i < m; i++) { scanf("%d %d", &c, &e); b[e] += c; }

    for (i = 0; i <= 1000; i++) {
        if (!a[i]) continue;
        for (j = 0; j <= 1000; j++)
            if (b[j]) mul[i + j] += a[i] * b[j];
    }
    for (i = 0; i <= 1000; i++) add[i] = a[i] + b[i];

    print(mul, 0, 2000);
    print(add, 0, 1000);
    return 0;
}
```

（`OFF` 宏是预留给负指数用的偏移量，当前未使用。）

### 3.5 易错点

1. **零多项式**：和多项式可能全部抵消，必须输出 `0 0`；输入项数为 0 时乘积也是 `0 0`。
2. **行尾空格**：用 `first` 标志而不是"每项后面加空格"。
3. **系数为 0 的项不输出**：必须在输出时判断。
4. 题面说"绝对值不超过 1000"，但样例指数都非负。若测试出现**负指数**，需要整体加偏移量 `OFF`，下标改为 `e+OFF`，数组随之扩大。目前代码按非负指数处理。
5. 全局数组默认初始化为 0，直接累加；若放在函数内要手动清零。

### 3.6 复杂度与另一种做法

- 数组法：时间 O(1000²)，空间 O(指数范围)。简单，适合指数范围小。
- **链表法**（教材标准做法）：每项一个结点，按指数递降串成链，乘法时逐项相乘再"插入有序链表并合并同类项"。指数范围很大但项数少（稀疏多项式）时更省空间。考试可能考链表写法，建议之后自己练一遍。

## 4. 题 7-2 两个有序链表序列的合并

### 4.1 题目

给两个非降序序列（以 `-1` 结尾，`-1` 不属于序列），构造合并后的非降序链表，一行输出，数字间空格分隔、结尾无多余空格；结果为空输出 `NULL`。

```
输入：
1 3 5 -1
2 4 6 8 10 -1

输出：
1 2 3 4 5 6 8 10
```

### 4.2 思路：归并（Merge）

两个有序序列各放一个指针 `a`、`b`，每次比较当前元素，**小的先接到结果后面**，该指针后移。一方走完后，把另一方剩余部分**整段接上**（它们本来就是有序的，不用再逐个比较）。

```
S1: 1 → 3 → 5
S2: 2 → 4 → 6 → 8 → 10

比 1,2 → 取 1    比 3,2 → 取 2    比 3,4 → 取 3
比 5,4 → 取 4    比 5,6 → 取 5    S1 空 → 接上 6 8 10
```

这是**归并排序**中"合并"步骤的原型，必须掌握。

### 4.3 技巧

- **尾指针 `t`**：始终指向结果链表的最后一个结点，尾插 O(1)，不用每次从头走。
- **头结点**：结果链表用一个哑头结点 `h3`，避免"结果为空时的特殊判断"。
- **复用原结点**：不新建结点，直接把原结点接过来，空间 O(1)。
- **等号取左**：`a->data <= b->data` 取 a，保证相等元素 S1 的在前（稳定性）。

### 4.4 代码

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node *read()                                   // 读一行，建带头结点的链表（尾插法）
{
    Node *head = (Node *)malloc(sizeof(Node)), *tail = head;
    int x;
    head->next = NULL;
    while (scanf("%d", &x) == 1 && x != -1) {
        Node *p = (Node *)malloc(sizeof(Node));
        p->data = x;
        p->next = NULL;
        tail->next = p;
        tail = p;
    }
    return head;
}

int main()
{
    Node *h1 = read(), *h2 = read();
    Node *a = h1->next, *b = h2->next;
    Node *h3 = (Node *)malloc(sizeof(Node)), *t = h3;
    int first = 1;

    while (a && b) {                           // 双指针归并
        if (a->data <= b->data) { t->next = a; a = a->next; }
        else { t->next = b; b = b->next; }
        t = t->next;
    }
    t->next = a ? a : b;                       // 接上剩余部分

    for (t = h3->next; t; t = t->next) {
        if (!first) printf(" ");
        printf("%d", t->data);
        first = 0;
    }
    if (first) printf("NULL");                 // 空链表
    printf("\n");
    return 0;
}
```

### 4.5 易错点

1. **忘记接剩余部分** `t->next = a ? a : b;`，结果少数据。
2. **空链表**输出 `NULL`。两行都只有 `-1` 时会触发。
3. 读入用 `scanf("%d") == 1 && x != -1`，同时兼顾 EOF 和结尾标志。
4. 尾插法需要 `tail` 指针，否则每次从头遍历变成 O(n²)。
5. 行尾空格：同 7-1，用 `first`。

### 4.6 复杂度

时间 O(m+n)，空间 O(1)（不算输入建表）。

## 5. 汇总：本批题目的通用技巧

### 5.1 顺序表 vs 链表速记

```
顺序表：改位置靠"挪元素"，Last 是下标，空 = -1，满 = MAXSIZE-1
链表  ：改位置靠"改指针"，要先找前驱，头结点统一操作
```

### 5.2 链表指针操作口诀

- **插入**：先让新结点指向后面，再让前面指向新结点。
- **删除**：前驱跳过目标结点，再 `free`。
- **遍历**：`while (p)`，**永远先判空再解引用**。
- 用 `&&` 的短路特性保护：`while (p && p->Data != X)`。

### 5.3 头结点的作用

| 无头结点                                 | 有头结点                              |
| ---------------------------------------- | ------------------------------------- |
| 操作第一个结点要单独处理，函数要改头指针 | 所有位置统一处理，头指针 `L` 始终不变 |

### 5.4 输出格式的通用套路

```c
int first = 1;
for (...) {
    if (!first) printf(" ");
    printf("%d", x);
    first = 0;
}
if (first) printf("特殊情况");   // 空
printf("\n");
```
