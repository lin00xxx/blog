## 1. Web Storage

Web Storage 是浏览器提供的本地存储能力，常用于保存用户偏好、临时数据、登录状态辅助信息等。

### 1.1 localStorage 与 sessionStorage

| 类型             | 生命周期                   | 作用域       | 常见用途                   |
| ---------------- | -------------------------- | ------------ | -------------------------- |
| `localStorage`   | 除非手动删除，否则长期存在 | 同源页面共享 | 主题色、语言偏好、长期缓存 |
| `sessionStorage` | 页面会话结束后清除         | 当前标签页   | 表单临时保存、单页流程数据 |

注意：Web Storage 只能保存字符串。如果要保存对象或数组，需要使用 `JSON.stringify()` 和 `JSON.parse()`。

### 1.2 常用 API

```js
// 保存数据
localStorage.setItem('username', 'Tom');

// 读取数据
const username = localStorage.getItem('username');

// 删除指定数据
localStorage.removeItem('username');

// 清空所有 localStorage 数据
localStorage.clear();
```

保存对象：

```js
const user = {
  id: 1,
  name: 'Tom',
  age: 18
};

localStorage.setItem('user', JSON.stringify(user));

const userStr = localStorage.getItem('user');
const userObj = JSON.parse(userStr);

console.log(userObj.name); // Tom
```

### 1.3 storage 事件

当同源页面中的一个页面修改了 `localStorage`，其他页面可以通过 `storage` 事件监听变化。

```js
window.addEventListener('storage', function (event) {
  console.log('key:', event.key);
  console.log('oldValue:', event.oldValue);
  console.log('newValue:', event.newValue);
});
```

注意：触发修改的当前页面本身通常不会收到这个事件，其他同源页面才会收到。

## 2. 正则表达式

正则表达式用于匹配字符串，常见场景包括表单校验、文本搜索、字符串替换、内容提取等。

### 2.1 创建正则表达式

字面量方式：

```js
const reg = /hello/;
```

构造函数方式：

```js
const reg = new RegExp('hello');
```

一般推荐使用字面量方式；如果正则内容需要由变量拼接生成，可以使用构造函数。

### 2.2 常用方法

```js
const reg = /\d+/;

console.log(reg.test('abc123')); // true
console.log('abc123'.match(reg)); // ['123']
console.log('abc123'.replace(reg, '***')); // abc***
```

| 方法        | 所属对象 | 作用                     |
| ----------- | -------- | ------------------------ |
| `test()`    | RegExp   | 判断是否匹配，返回布尔值 |
| `exec()`    | RegExp   | 执行匹配，返回匹配结果   |
| `match()`   | String   | 查找匹配内容             |
| `replace()` | String   | 替换匹配内容             |
| `split()`   | String   | 按正则分割字符串         |

### 2.3 常用元字符

| 写法 | 含义                 | 示例     |
| ---- | -------------------- | -------- |
| `\d` | 数字，等价于 `[0-9]` | `/\d/`   |
| `\D` | 非数字               | `/\D/`   |
| `\w` | 字母、数字、下划线   | `/\w/`   |
| `\W` | 非字母、数字、下划线 | `/\W/`   |
| `\s` | 空白字符             | `/\s/`   |
| `\S` | 非空白字符           | `/\S/`   |
| `.`  | 除换行外的任意字符   | `/a.c/`  |
| `^`  | 字符串开始           | `/^abc/` |
| `$`  | 字符串结束           | `/abc$/` |

### 2.4 常用量词

| 写法    | 含义             |
| ------- | ---------------- |
| `*`     | 出现 0 次或多次  |
| `+`     | 出现 1 次或多次  |
| `?`     | 出现 0 次或 1 次 |
| `{n}`   | 出现 n 次        |
| `{n,}`  | 至少出现 n 次    |
| `{n,m}` | 出现 n 到 m 次   |

示例：

```js
const phoneReg = /^1[3-9]\d{9}$/;

console.log(phoneReg.test('13812345678')); // true
console.log(phoneReg.test('123')); // false
```

### 2.5 分组与捕获

```js
const date = '2026-07-12';
const reg = /(\d{4})-(\d{2})-(\d{2})/;

const result = date.match(reg);

console.log(result[1]); // 2026
console.log(result[2]); // 07
console.log(result[3]); // 12
```

在 `replace()` 中使用捕获组：

```js
const date = '2026-07-12';

const result = date.replace(/(\d{4})-(\d{2})-(\d{2})/, '$1年$2月$3日');

console.log(result); // 2026年07月12日
```

### 2.6 贪婪匹配与非贪婪匹配

默认情况下，量词会尽可能多地匹配内容，这叫贪婪匹配。

```js
const str = '<div>hello</div><div>world</div>';

console.log(str.match(/<div>.*<\/div>/)[0]);
// <div>hello</div><div>world</div>
```

在量词后面加 `?`，可以变成非贪婪匹配。

```js
const str = '<div>hello</div><div>world</div>';

console.log(str.match(/<div>.*?<\/div>/)[0]);
// <div>hello</div>
```

### 2.7 常见校验示例

```js
// 手机号
const phoneReg = /^1[3-9]\d{9}$/;

// 邮箱，适合基础校验
const emailReg = /^[\w.-]+@[\w.-]+\.[A-Za-z]{2,}$/;

// 用户名：字母、数字、下划线，长度 6 到 16
const usernameReg = /^\w{6,16}$/;

// 密码：至少 8 位，必须包含字母和数字
const passwordReg = /^(?=.*[A-Za-z])(?=.*\d)[A-Za-z\d]{8,}$/;
```

## 3. 闭包

闭包是 JavaScript 中非常重要的概念。（内层函数用到了他上层函数环境里（不是全局）的变量等）

闭包是函数 函数不一定是闭包

### 3.1 闭包的基本例子

```js
function outer() {
  const name = 'Tom';

  function inner() {
    console.log(name);
  }

  return inner;
}

const fn = outer();
fn(); // Tom
```

`outer()` 执行结束后，按理说它的局部变量应该被销毁。但由于 `inner()` 仍然引用了 `name`，所以 `name` 会被保留下来。

### 3.2 闭包的作用

#### 1. 保存私有变量

```js
function createCounter() {
  let count = 0;

  return function () {
    count++;
    return count;
  };
}
//闭包必须嵌套在函数里面并访问这个函数作用域的变量 并且需要return外部才能调用这个嵌套函数
const counter = createCounter();

console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
```

`count` 外部可以访问，但只能通过返回的函数修改。

#### 2. 封装模块状态

意思是把要操作的数据和操作方法放在一起 避免暴露数据

```js
function createUser() {
  let name = '未命名';
	//let跟const的区别在于let定义的变量后续可以修改
  return {
    getName() {
      return name;
    },
    setName(newName) {
      name = newName;
    }
  };
}

const user = createUser();
user.setName('Alice');

console.log(user.getName()); // Alice
```

#### 3. 延长变量生命周期

```js
function delayLog(message) {
  setTimeout(function () {
    console.log(message);
  }, 1000);
}

delayLog('hello');
```

`message` 在 1 秒后仍然可以被访问，这就是闭包的体现。

###### 闭包延长生命周期的本质

1. **垃圾回收机制**：
   - JavaScript 引擎会定期回收不再使用的变量（垃圾回收）。
   - 如果一个变量还被其他函数引用，它就不会被回收。
2. **闭包的作用**：
   - 回调函数引用了外部的 `message`。
   - 所以 `message` 不会被回收，延长了生命周期。

### 3.3 闭包常见面试题

```js
for (var i = 0; i < 3; i++) {
  setTimeout(function () {
    console.log(i);
  }, 1000);
}
```

输出结果：

```txt
3
3
3
```

原因：for循环是同步步骤 0ms就执行完了三次 创建了三次settimeout 并且每次的i会跟着全部的变 但闭包函数异步的 等待执行三次回调 执行他们的时候 i已经变成了3

` var` 没有块级作用域，三个定时器共享同一个 `i`。

1. **`setTimeout` 即使是 0ms 也是异步的**：
   - 它不会立即执行回调函数。
   - 只是把回调函数放入任务队列。
2. **执行顺序**：
   - 先执行所有同步代码。
   - 然后执行异步回调。

解决方式一：使用 `let`。let让每次循环创建出来的闭包各自拥有一个i 等到最后再输出

```js
for (let i = 0; i < 3; i++) {
  setTimeout(function () {
    console.log(i);
  }, 1000);
}
```

输出：

```txt
0
1
2
```

解决方式二：使用立即执行函数。

```js
for (var i = 0; i < 3; i++) {
  (function (index) {
    setTimeout(function () {
      console.log(index);
    }, 1000);
  })(i);
}
```

解决方法三：使用 setTimeout 的第三个参数

```js
for(var i = 0;i < 3;i++){
    setTimeout(function(j){
        console.log(j);
    },1000,i);
}
```

### 3.4 闭包易错点

- 闭包会让被引用的变量继续保存在内存中。
- 不要滥用闭包，否则可能造成内存占用过高。
- 闭包中访问的是变量本身，不是变量创建时的值。

## 4. 立即执行函数

立即执行函数，全称 IIFE：Immediately Invoked Function Expression。它的特点是函数定义后立即执行不用命名。

### 4.1 基本写法

```js
(function () {
  console.log('立即执行');
})();
//括号里可以传参
```

也可以这样写：

```js
(function () {
  console.log('立即执行');
}());
```

箭头函数写法：

```js
(() => {
  console.log('立即执行');
})();
```

### 4.2 为什么要加括号

下面写法会报错：

```js
function () {
  console.log('error');
}();
```

原因：JavaScript 会把 `function` 开头的代码当成函数声明，而函数声明必须有函数名。

加括号后，函数声明会变成<u>函数表达式</u>：function前面加个+或其他的运算符也可以 反正要变成表达式

```js
(function () {
  console.log('ok');
})();
```

### 4.3 IIFE 的作用

const version = '1.0.0'

#### 1. 创建独立作用域 

#### 	封闭空间

```js
(function () {
  const message = 'hello';
  console.log(message);
})();

console.log(message); // 报错，外部访问不到
```

#### 2. 避免全局变量污染

```js
(function () {
  const version = '1.0.0';

  function init() {
    console.log('init', version);
  }

  init();
})();
```

#### 3. 配合闭包保存变量

```js
const auth = (function () {
  let token = 0;

  return {
    getToken() {
      return count;
    },
    setToken(newToken) {
      token = newToken;
      return token;
    }
  };
})();

console.log(counter.add()); // 1
console.log(counter.add()); // 2
console.log(counter.reset()); // 0
```

## 5. this 指向

`this` 表示函数执行时的上下文。它的值不是在函数定义时决定的，而是在函数调用时决定的。

### 5.1 普通函数中的 this

#### 1. 全局调用

```js
function fn() {
  console.log(this);//指向window
}

fn(); //实际上是window.fn()
```

在非严格模式下，浏览器中 `this` 指向 `window`。在严格模式下，`this` 是 `undefined`。

```js
'use strict';

function fn() {
  console.log(this); // undefined
}

fn(); 
```

#### 2. 对象方法调用

```js
const user = {
  name: 'Tom',
  sayHi() {
    console.log(this.name);
  }
};

user.sayHi(); // Tom
```

谁调用函数，普通函数中的 `this` 通常就指向谁。

#### 3. 构造函数调用

```js
function User(name) {
  this.name = name;
}

const user = new User('Tom');
s
console.log(user.name); // Tom
```

使用 `new` 调用函数时，`this` 指向新创建的对象。

#### 4. 事件处理函数

```js
const button = document.querySelector('button');

button.addEventListener('click', function () {
  console.log(this); // button
});
```

普通函数作为事件处理函数时，`this` 通常指向绑定事件的元素。

因为调用时是这样的：button.onclick=function(){ .... }

​					节点是button   button.function( )

### 5.2 改变 this 指向

#### call()

```js
function sayHi(age) {
  console.log(this.name, age);
}

const user = { name: 'Tom' };

sayHi.call(user, 18); // Tom 18  原来指向sayhi的this指向为user
```

#### apply()

```js
function sayHi(age, city) {
  console.log(this.name, age, city);
}

const user = { name: 'Tom' };

sayHi.apply(user, [18, 'Beijing']); // Tom 18 Beijing
```

#### bind()

```js
function sayHi() {
  console.log(this.name);
}

const user = { name: 'Tom' };
const newFn = sayHi.bind(user);

newFn(); // Tom
```

| 方法      | 是否立即执行 | 参数形式                               |
| --------- | ------------ | -------------------------------------- |
| `call()`  | 是           | 逐个传入，可以传入n个参数              |
| `apply()` | 是           | 就接受两个参数，想要传入多个需数组传入 |
| `bind()`  | 否           | 不会自动执行函数，逐个传入，返回新函数 |

### 5.3 this 易错题

```js
const user = {
  name: 'Tom',
  sayHi: function () {
    console.log(this.name);
  }
};

const fn = user.sayHi;
fn(); // 非严格模式下通常是 window
```

原因：只传递了函数本身没有传递方法`fn()` 是普通函数调用，不再是 `user.sayHi()` 的对象方法调用。

修复：

```js
const fn = user.sayHi.bind(user);
fn(); // Tom
```

## 6. Promise

Promise 是 JavaScript 处理异步操作的重要方式。它解决了传统回调函数容易层层嵌套的问题。

promise是取餐号 是一个类 实际存在的存放未来会出现的东西的对象

### 6.1 Promise 的三种状态

| 状态        | 含义   |
| ----------- | ------ |
| `pending`   | 等待中 |
| `fulfilled` | 已成功 |
| `rejected`  | 已失败 |

状态变化只能有两种：

- `pending` -> `fulfilled`
- `pending` -> `rejected`

一旦状态改变，就不会再变。

### 6.2 基本写法

```js
const promise = new Promise(function (resolve, reject) {
  const success = true;

  if (success) {
    resolve('成功结果');
  } else {
    reject('失败原因');
  }
});

promise
  .then(function (result) {
    console.log(result);
  })
  .catch(function (error) {
    console.log(error);
  });
```

resolve传给then reject传给catch

### 6.3 then 链式调用

*.then() 的作用就是：当这个真实的 Promise 对象状态变成 fulfilled 时，把里面的结果拿出来交给你*

```js
function getUser() {
  return new Promise(function (resolve) {
    setTimeout(function () {
      resolve({ id: 1, name: 'Tom' });
    }, 1000);
  });
}

function getOrders(userId) {
  return new Promise(function (resolve) {
    setTimeout(function () {
      resolve(['订单1', '订单2']);
    }, 1000);
  });
}

getUser()
  .then(function (user) {
    console.log(user);
    return getOrders(user.id);
  })
  .then(function (orders) {
    console.log(orders);
  })
  .catch(function (error) {
    console.log(error);
  });
```

`then()` 中返回一个新的 Promise，后面的 `then()` 会等待它完成。

### 6.4 catch 捕获错误

```js
Promise.resolve()
  .then(function () {
    throw new Error('出错了');
  })
  .catch(function (error) {
    console.log(error.message); // 出错了
  });
```

### 6.5 finally

无论成功还是失败，`finally()` 都会执行，常用于关闭 loading。

```js
requestData()
  .then(function (data) {
    console.log(data);
  })
  .catch(function (error) {
    console.log(error);
  })
  .finally(function () {
    console.log('请求结束');
  });
```

### 6.6 Promise.all()

多个异步任务全部成功后，才进入 `then()`。

```js
const p1 = Promise.resolve('A');
const p2 = Promise.resolve('B');
const p3 = Promise.resolve('C');

Promise.all([p1, p2, p3]).then(function (result) {
  console.log(result); // ['A', 'B', 'C']
});
```

只要有一个 Promise 失败，`Promise.all()` 就会失败。

### 6.7 Promise.race()

返回最先完成的 Promise，不管成功还是失败。

```js
const p1 = new Promise(function (resolve) {
  setTimeout(function () {
    resolve('p1');
  }, 1000);
});

const p2 = new Promise(function (resolve) {
  setTimeout(function () {
    resolve('p2');
  }, 500);
});

Promise.race([p1, p2]).then(function (result) {
  console.log(result); // p2
});
```

### 6.8 async 与 await 简介

`async/await` 是 Promise 的语法糖，可以让异步代码看起来像同步代码一样清晰。

简单理解：

- `async`：用来声明一个异步函数。
- `await`：用来等待一个 Promise 的结果。
- `try...catch`：用来捕获 `await` 过程中的错误。

#### 1. async 函数一定返回 Promise

只要一个函数前面加了 `async`，这个函数的返回值就一定是 Promise。

```js
async function fn() {
  return 'hello';
}

const result = fn();

console.log(result); // Promise
```

如果想拿到真正的返回值，可以使用 `then()`：（手动拆包）

*.then() 的作用就是：当这个真实的 Promise 对象状态变成 fulfilled 时，把里面的结果拿出来交给你*

```js
fn().then(function (data) {
  console.log(data); // hello
});
```

也可以在另一个 `async` 函数中使用 `await`：

```js
async function main() {
  const data = await fn();
  console.log(data); // hello
}

main();
```

#### 2. await 等待 Promise 完成

`await` 后面通常跟一个 Promise。它会等待 Promise 状态变成成功，然后把成功结果返回出来。（自动拆包）

```js
function getData() {
  return new Promise(function (resolve) {
    setTimeout(function () {
      resolve('数据加载完成');
    }, 1000);
  });
}

async function main() {
  const data = await getData();
  console.log(data); // 数据加载完成
}

main();
```

上面的代码可以理解为：

```txt
等待 getData() 执行完成
拿到异步返回的数据
打印数据
```

#### 3. 使用 try...catch 处理错误

如果 Promise 变成 `rejected` 状态，`await` 会抛出错误。实际开发中通常使用 `try...catch` 处理。

```js
function login(phone) {
  return new Promise(function (resolve, reject) {
    setTimeout(function () {
      if (phone === '13812345678') {
        resolve({
          phone,
          token: 'mock-token'
        });
      } else {
        reject(new Error('手机号不正确'));
      }
    }, 1000);
  });
}

async function main() {
  try {
    const user = await login('13812345678');
    console.log('登录成功', user);
  } catch (error) {
    console.log('登录失败', error.message);
  }
}

main();
```

#### 4. await 不会阻塞整个程序

`await` 只会暂停当前 `async` 函数中后面的代码，不会阻塞函数外部的代码。

```js
function delay(ms) {
  return new Promise(function (resolve) {
    setTimeout(resolve, ms);
  });
}

async function main() {
  console.log('1');

  await delay(1000);

  console.log('2');
}

main();

console.log('3');
```

输出顺序：

```txt
1
3
2
```

原因：

- `main()` 先执行，输出 `1`。
- 遇到 `await delay(1000)`，`main()` 暂停等待。
- 函数外面的 `console.log('3')` 继续执行。
- 1 秒后 Promise 完成，继续执行 `main()` 后面的代码，输出 `2`。

#### 5. 顺序执行与并发执行

如果两个异步任务有先后依赖关系，可以顺序执行。

```js
async function main() {
  const user = await getUser();
  const orders = await getOrders(user.id);

  console.log(user, orders);
}
```

如果两个异步任务互不依赖，推荐使用 `Promise.all()` 并发执行，效率更高。

```js
async function main() {
  const [user, banners] = await Promise.all([
    getUser(),
    getBanners()
  ]);

  console.log(user, banners);
}
```

#### 6. async/await 常见易错点

忘记写 `await`：

```js
async function main() {
  const data = getData();
  console.log(data); // Promise，不是真正的数据
}
```

正确写法：

```js
async function main() {
  const data = await getData();
  console.log(data);
}
```

误以为 `async` 函数返回普通值：

```js
async function getName() {
  return 'Tom';
}

console.log(getName()); // Promise
```

在 `forEach()` 中使用 `await` 时要小心：

```js
const list = [1, 2, 3];

list.forEach(async function (item) {
  await delay(1000);
  console.log(item);
});
```

这种写法不会等待所有异步任务执行结束。如果需要按顺序执行，可以使用 `for...of`：

```js
async function main() {
  const list = [1, 2, 3];

  for (const item of list) {
    await delay(1000);
    console.log(item);
  }
}
```

如果希望同时执行，可以使用 `Promise.all()`：

```js
async function main() {
  const list = [1, 2, 3];

  await Promise.all(
    list.map(async function (item) {
      await delay(1000);
      console.log(item);
    })
  );
}
```

#### 7. async/await 小总结

```txt
async：声明异步函数，返回值一定是 Promise
await：等待 Promise 完成，并取出成功结果
try...catch：捕获异步错误
Promise.all：让多个异步任务并发执行
```

## 7. ES6 箭头函数

箭头函数是 ES6 提供的函数简写语法。

### 7.1 基本语法

普通函数：

```js
const add = function (a, b) {
  return a + b;
};
```

箭头函数：

```js
const add = (a, b) => {
  return a + b;
};
```

如果函数体只有一行返回值，可以省略 `{}` 和 `return`：

```js
const add = (a, b) => a + b;
```

如果只有一个参数，可以省略参数括号：

```js
const double = n => n * 2;
var newlist=list.map(item=>`<li>${item}</li>`)
```

如果没有参数，括号不能省略：

```js
const sayHi = () => console.log('hi');
```

返回对象时，需要用括号包起来： 

```js
const createUser = name => ({ name });
```

### 7.2 箭头函数中的 this

箭头函数没有自己的 `this`，它会从外层作用域继承 `this`。

还可以再定义一个变量that，把外层的this赋值给它，自己里调用that

```js
const user = {
  name: 'Tom',
  sayHi: function () {
    setTimeout(() => {
      console.log(this.name);
    }, 1000);
  }
};

user.sayHi(); // Tom
```

这里的箭头函数继承了 `sayHi()` 中的 `this`，所以可以访问 `user.name`。

### 7.3 箭头函数不适合的场景

#### 1. 不适合作为对象方法

```js
const user = {
  name: 'Tom',
  sayHi: () => {
    console.log(this.name);
  }
};

user.sayHi(); // 通常不是 Tom
```

原因：箭头函数没有自己的 `this`，不会因为 `user.sayHi()` 调用而指向 `user`。

#### 2. 不适合作为构造函数

```js
const User = (name) => {
  this.name = name;
};

// const user = new User('Tom'); // 报错
```

箭头函数不能使用 `new` 调用。

#### 3. 不适合需要 arguments 的场景

箭头函数没有自己的 `arguments`。argument一般用在没有传入参数

```js
function fn() {
  const arrow = () => {
    console.log(arguments);
  };

  arrow();
}

fn(1, 2, 3); // 输出外层 fn 的 arguments
```

如果需要接收不定数量参数，推荐使用剩余参数：

```js
const sum = (...nums) => {
  return nums.reduce((total, item) => total + item, 0);
};

console.log(sum(1, 2, 3)); // 6
```

### 7.4 箭头函数常见应用

数组遍历：

```js
const nums = [1, 2, 3];

const result = nums.map(item => item * 2);

console.log(result); // [2, 4, 6]
```

数组筛选：

```js
const users = [
  { name: 'Tom', age: 18 },
  { name: 'Alice', age: 20 },
  { name: 'Jack', age: 16 }
];

const adults = users.filter(user => user.age >= 18);

console.log(adults);
```

Promise 中使用：

```js
fetch('/api/user')
  .then(res => res.json())
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.log(error);
  });
```
