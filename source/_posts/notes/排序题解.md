# 算法题整理

## 1. 俄罗斯套娃问题

### 题目描述
给定一个序列，每次只能交换相邻的两个元素，求最少交换次数使序列升序。如果交换次数超过 $n(n-1)/2 - 1$，则输出 "NO"，否则输出 "YES"。

### 知识点详解

#### 1. 数组输入与存储
```c
int n;
scanf("%d", &n);  // 读取整数n
int a[1005];       // 定义数组，大小1005（n<=1000）
for (int i = 0; i < n; i++) {
    scanf("%d", &a[i]);  // 循环读取n个整数到数组
}
```
- `scanf` 函数：从标准输入读取数据
- `&a[i]`：取数组元素的地址
- 数组下标从0开始

#### 2. 完全倒序判断
```c
int is_desc = 1;  // 假设是完全倒序
for (int i = 0; i < n - 1; i++) {
    if (a[i] <= a[i + 1]) {  // 只要有一个不是递减
        is_desc = 0;
        break;
    }
}
```
- `for` 循环：遍历数组
- `break`：立即跳出循环
- 布尔变量：用0/1表示真/假

#### 3. 条件判断与输出
```c
if (is_desc && n > 1) printf("NO\n");
else printf("YES\n");
```
- `&&`：逻辑与运算
- `printf`：格式化输出
- `\n`：换行符

### 完整代码
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    int a[1005];
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    
    int is_desc = 1;
    for (int i = 0; i < n - 1; i++) {
        if (a[i] <= a[i + 1]) {
            is_desc = 0;
            break;
        }
    }
    
    if (is_desc && n > 1) printf("NO\n");
    else printf("YES\n");
    
    return 0;
}
```

## 2. Ultra-QuickSort（求逆序对）

### 题目描述
求一个序列的逆序对数量。$n \le 500000$，必须用 $O(n \log n)$ 算法。

### 知识点详解

#### 1. 归并排序原理
- 分治思想：将数组分成两半，分别排序，再合并
- 递归实现
- 合并过程统计逆序对

#### 2. 递归函数设计
```c
long long merge_sort(int a[], int left, int right, int temp[]) {
    if (left >= right) return 0;  // 递归边界
    
    int mid = left + (right - left) / 2;
    long long count = merge_sort(a, left, mid, temp) + merge_sort(a, mid + 1, right, temp);
    // ... 合并过程 ...
}
```
- 递归函数：自己调用自己
- `long long`：防止大数溢出
- 数组作为参数：传递整个数组

#### 3. 合并过程
```c
int i = left, j = mid + 1, k = left;
while (i <= mid && j <= right) {
    if (a[i] <= a[j]) {
        temp[k++] = a[i++];
    } else {
        count += (mid - i + 1);  // 统计逆序对
        temp[k++] = a[j++];
    }
}
```
- 双指针法：分别指向两个子数组
- `temp` 数组：临时存储合并结果
- 逆序对统计：左边剩余元素都构成逆序对

#### 4. 内存管理
```c
int *a = (int *)malloc(n * sizeof(int));
int *temp = (int *)malloc(n * sizeof(int));
// ... 使用 ...
free(a);
free(temp);
```
- `malloc`：动态内存分配
- `sizeof`：获取类型大小
- `free`：释放内存

### 完整代码
```c
#include <stdio.h>
#include <stdlib.h>

long long merge_sort(int a[], int left, int right, int temp[]) {
    if (left >= right) return 0;
    
    int mid = left + (right - left) / 2;
    long long count = merge_sort(a, left, mid, temp) + merge_sort(a, mid + 1, right, temp);
    
    int i = left, j = mid + 1, k = left;
    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) {
            temp[k++] = a[i++];
        } else {
            count += (mid - i + 1);
            temp[k++] = a[j++];
        }
    }
    while (i <= mid) temp[k++] = a[i++];
    while (j <= right) temp[k++] = a[j++];
    for (i = left; i <= right; i++) a[i] = temp[i];
    
    return count;
}

int main() {
    int n;
    while (scanf("%d", &n) != EOF && n != 0) {
        int *a = (int *)malloc(n * sizeof(int));
        int *temp = (int *)malloc(n * sizeof(int));
        
        for (int i = 0; i < n; i++) scanf("%d", &a[i]);
        
        long long ans = merge_sort(a, 0, n - 1, temp);
        printf("%lld\n", ans);
        
        free(a);
        free(temp);
    }
    return 0;
}
```

## 3. 明明的随机数（去重排序）

### 题目描述
对 $n$ 个 1~1000 的随机数去重并排序。

### 知识点详解

#### 1. 计数排序原理
- 利用数值范围小的特点
- 开一个足够大的数组
- 用下标表示数值，用值表示存在性

#### 2. 计数数组初始化
```c
int count[1001] = {0};  // 全部初始化为0
```
- 数组大小：1001（0~1000）
- `{0}`：初始化列表

#### 3. 标记存在性
```c
for (int i = 0; i < n; i++) {
    int x;
    scanf("%d", &x);
    count[x] = 1;  // 标记x存在
}
```
- 输入处理：`scanf`
- 标记：直接赋值1

#### 4. 统计和输出
```c
int m = 0;
for (int i = 1; i <= 1000; i++) {
    if (count[i]) m++;  // 统计存在的数
}
printf("%d\n", m);
for (int i = 1; i <= 1000; i++) {
    if (count[i]) printf("%d ", i);
}
```
- 条件判断：`if (count[i])`
- 循环输出：遍历计数数组

### 完整代码
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    int count[1001] = {0};
    
    for (int i = 0; i < n; i++) {
        int x;
        scanf("%d", &x);
        count[x] = 1;
    }
    
    int m = 0;
    for (int i = 1; i <= 1000; i++) {
        if (count[i]) m++;
    }
    
    printf("%d\n", m);
    for (int i = 1; i <= 1000; i++) {
        if (count[i]) printf("%d ", i);
    }
    
    return 0;
}
```

## 4. 结构体排序（多级排序）

### 题目描述
对长方形按 id → length → width 多级排序，并去重。

### 知识点详解

#### 1. 结构体定义
```c
typedef struct {
    int id;
    int length;
    int width;
} Rectangle;
```
- `typedef`：类型别名
- 结构体：自定义数据类型
- 成员变量：id, length, width

#### 2. 复合字面量
```c
rects[i] = (Rectangle){id, a, b};
```
- 临时创建结构体
- 直接初始化
- 等价于：
```c
Rectangle temp;
temp.id = id;
temp.length = a;
temp.width = b;
rects[i] = temp;
```

#### 3. qsort 排序
```c
qsort(rects, m, sizeof(Rectangle), compare);
```
- `qsort`：标准库排序函数
- 参数：
  - 数组指针
  - 元素个数
  - 单个元素大小
  - 比较函数

#### 4. 比较函数
```c
int compare(const void *a, const void *b) {
    Rectangle *ra = (Rectangle *)a;
    Rectangle *rb = (Rectangle *)b;
    return (ra->id != rb->id) ? (ra->id - rb->id) :
           (ra->length != rb->length) ? (ra->length - rb->length) :
           (ra->width - rb->width);
}
```
- `const void *`：通用指针
- 类型转换：`(Rectangle *)`
- 三元运算符：`?:`
- 成员访问：`->`

#### 5. 先排序后去重
```c
int unique_count = 0;
for (int i = 0; i < m; i++) {
    if (i == 0 || 
        rects[i].id != rects[i-1].id ||
        rects[i].length != rects[i-1].length ||
        rects[i].width != rects[i-1].width) {
        rects[unique_count++] = rects[i];
    }
}
```
- 线性扫描
- 相邻元素比较
- 计数器递增

### 完整代码
```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int id;
    int length;
    int width;
} Rectangle;

int compare(const void *a, const void *b) {
    Rectangle *ra = (Rectangle *)a;
    Rectangle *rb = (Rectangle *)b;
    return (ra->id != rb->id) ? (ra->id - rb->id) :
           (ra->length != rb->length) ? (ra->length - rb->length) :
           (ra->width - rb->width);
}

int main() {
    int n;
    scanf("%d", &n);
    while (n--) {
        int m;
        scanf("%d", &m);
        Rectangle rects[1000];
        
        for (int i = 0; i < m; i++) {
            int id, a, b;
            scanf("%d %d %d", &id, &a, &b);
            if (a < b) { int temp = a; a = b; b = temp; }
            rects[i] = (Rectangle){id, a, b};
        }
        
        qsort(rects, m, sizeof(Rectangle), compare);
        
        int unique_count = 0;
        for (int i = 0; i < m; i++) {
            if (i == 0 || 
                rects[i].id != rects[i-1].id ||
                rects[i].length != rects[i-1].length ||
                rects[i].width != rects[i-1].width) {
                rects[unique_count++] = rects[i];
            }
        }
        
        for (int i = 0; i < unique_count; i++) {
            printf("%d %d %d\n", rects[i].id, rects[i].length, rects[i].width);
        }
    }
    return 0;
}
```

## 5. 插入排序

### 题目描述
用插入排序对 $n$ 个数进行排序。

### 知识点详解

#### 1. 插入排序原理
- 将数组分为已排序和未排序两部分
- 每次取出未排序部分的第一个元素
- 在已排序部分找到正确位置并插入

#### 2. 核心算法
```c
for (int i = 1; i < n; i++) {
    int key = a[i];        // 当前要插入的元素
    int j = i - 1;        // 已排序部分的最后一个位置
    while (j >= 0 && a[j] > key) {
        a[j + 1] = a[j];   // 元素后移
        j--;
    }
    a[j + 1] = key;       // 插入到正确位置
}
```
- `for` 循环：遍历未排序部分
- `while` 循环：在已排序部分找位置
- 元素移动：`a[j + 1] = a[j]`

#### 3. 输入输出
```c
for (int i = 0; i < n; i++) {
    scanf("%d", &a[i]);   // 读取输入
}
for (int i = 0; i < n; i++) {
    printf("%d ", a[i]);  // 输出结果
}
```
- 循环输入输出
- 格式控制：空格分隔

### 完整代码
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    int a[100005];
    
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }
    
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
    
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    
    return 0;
}
```
