# 二分查找、贪心、几何枚举与数值枚举

这份笔记整理了最近练习的 4 道题：

1.  穿梭星球：移走最多 M 个星球，让最小相邻距离最大。
2.  星星组成正方形：给定二维坐标，统计正方形数量。
3.  电缆分割：把现有电缆切成至少 K 段等长电缆，求最长长度。
4.  赌徒下注：判断某个数是否等于另外三个不同数之和，输出最大的获胜值。

重点不是背代码，而是学会识别题型、确定"枚举什么"、以及判断答案是否可行。

------------------------------------------------------------------------

## 一、穿梭星球：二分答案 + 贪心

### 1. 题目在问什么？

起点是 0，终点是 L，中间有 N 个星球。允许移走 M
个中间星球，要求移走后相邻保留星球的最小距离尽可能大。

### 2. 解题思路

直接尝试所有可能的答案很麻烦，因此二分"最小距离"。

假设猜测最小距离为 `mid`，从左向右检查星球：

-   如果当前星球与上一个保留星球的距离小于 `mid`，就移走当前星球。
-   否则保留当前星球，并把它作为新的上一个保留星球。
-   最后，如果移走数量不超过 M，说明 `mid`
    可行，可以继续尝试更大的距离；否则距离太大，需要尝试更小的距离。

这里的贪心策略是：距离不够时，移走当前星球，让上一个保留星球保持不变。

### 3. 关键代码

``` c
int left = 0, right = L, ans = 0;

while (left <= right)
{
    int mid = (left + right) / 2;
    int removed = 0;
    int last = 0;  // 起点的下标

    for (int i = 1; i <= N + 1; i++)
    {
        if (D[i] - D[last] < mid)
            removed++;
        else
            last = i;
    }

    if (removed <= M)
    {
        ans = mid;
        left = mid + 1;   // 可行，尝试更大
    }
    else
    {
        right = mid - 1;  // 不可行，尝试更小
    }
}

printf("%d\n", ans);
```

数组需要提前补上起点和终点：

``` c
D[0] = 0;
// 中间星球读入 D[1] 到 D[N]
D[N + 1] = L;
```

### 4. 对应知识点

-   二分查找答案：不是在数组里找某个数，而是在答案范围里找最大可行值。
-   贪心：每一步按规则做局部选择。
-   `last`：上一个保留星球的下标。
-   `removed`：当前猜测距离需要移走的星球数。

### 5. 识别技巧

看到"最大化最小值""最小距离尽可能大"，并且能判断某个距离是否可行时，可以考虑二分答案。

## 二、星星组成正方形：枚举边 + 坐标变换 + 查找

### 1. 题目在问什么？

给出 N
个二维坐标，问其中有多少组点可以组成正方形。正方形可能倾斜，不一定与坐标轴平行。

### 2. 解题思路

正方形的四个顶点中，任选一条边 AB。假设：

-   A = `(x1, y1)`
-   B = `(x2, y2)`
-   `dx = x2 - x1`
-   `dy = y2 - y1`

把向量 `(dx, dy)` 旋转 90°，可以得到垂直方向的向量
`(-dy, dx)`。因此，正方形的另外两个顶点可以是：

-   `(x1 - dy, y1 + dx)` 和 `(x2 - dy, y2 + dx)`
-   或 `(x1 + dy, y1 - dx)` 和 `(x2 + dy, y2 - dx)`

两种方向都要检查。若另外两个点也存在，就找到了一个正方形。

### 3. 关键代码：由一条边算出另外两个点

``` c
int dx = p[j].x - p[i].x;
int dy = p[j].y - p[i].y;

/* 向量旋转 90 度的一种方向 */
int x3 = p[i].x - dy;
int y3 = p[i].y + dx;
int x4 = p[j].x - dy;
int y4 = p[j].y + dx;

/* 检查 (x3,y3) 和 (x4,y4) 是否都存在 */

/* 另一种旋转方向 */
x3 = p[i].x + dy;
y3 = p[i].y - dx;
x4 = p[j].x + dy;
y4 = p[j].y - dx;

/* 再检查一次 */
```

### 4. 如何判断坐标是否存在？

可以先按 x、y 排序，再用二分查找。排序后，坐标按 `(x, y)` 的字典序排列。

``` c
int find(int x, int y, int n)
{
    int left = 0, right = n - 1;

    while (left <= right)
    {
        int mid = (left + right) / 2;

        if (p[mid].x == x && p[mid].y == y)
            return 1;

        if (p[mid].x < x ||
            (p[mid].x == x && p[mid].y < y))
            left = mid + 1;
        else
            right = mid - 1;
    }

    return 0;
}
```

### 5. 为什么最后除以 4？

同一个正方形的四条边都可能被枚举为 AB，因此每个正方形会被统计 4
次，最终答案要除以 4。

``` c
printf("%lld\n", ans / 4);
```

完整枚举的核心：

``` c
long long ans = 0;

for (int i = 0; i < n; i++)
{
    for (int j = i + 1; j < n; j++)
    {
        /* 根据 p[i]、p[j] 计算另外两个点 */
        /* 两种旋转方向分别判断 */
        /* 每找到一组符合条件的顶点，ans++ */
    }
}

printf("%lld\n", ans / 4);
```

### 6. 对应知识点

-   枚举：枚举每一对点，尝试把它们作为正方形的一条边。
-   二维坐标与向量：用坐标差 `(dx, dy)` 表示边的方向。
-   旋转 90°：`(dx, dy)` 旋转后变为 `(-dy, dx)` 或 `(dy, -dx)`。
-   排序 + 二分查找：快速判断一个坐标是否存在。
-   去重计数：考虑同一个正方形被重复统计了几次。

### 7. 识别技巧

看到"给出点的坐标，统计能组成多少个图形"，先想：

1.  枚举哪些点或边？
2.  能否根据已知点计算剩余顶点？
3.  如何快速判断计算出的点是否存在？
4.  同一个图形会不会被重复统计？

## 三、电缆分割：二分答案 + 贪心计数

### 1. 题目在问什么？

有 N 根电缆，长度精确到厘米。要切出至少 K
段等长电缆，求每段电缆最长能有多少米。

### 2. 关键技巧：统一换算成厘米

由于长度精确到厘米，直接用整数厘米计算更方便，也避免浮点数比较造成误差。

例如 `8.02` 米换成 `802` 厘米。

``` c
double x;
scanf("%lf", &x);
len[i] = (int)(x * 100 + 0.5);
```

### 3. 解题思路

二分每段电缆的长度 `mid`（单位：厘米）。

如果某根电缆长度为 `len[i]`，它能切出：

``` c
len[i] / mid
```

段长度为 `mid` 的电缆。

把所有电缆能切出的段数相加：

-   总段数 `>= K`：长度可行，可以尝试更长。
-   总段数 `< K`：长度太长，需要缩短。

### 4. 关键代码

``` c
int left = 1, right = maxLen, ans = 0;

while (left <= right)
{
    int mid = (left + right) / 2;
    int pieces = 0;

    for (int i = 0; i < N; i++)
        pieces += len[i] / mid;

    if (pieces >= K)
    {
        ans = mid;
        left = mid + 1;
    }
    else
    {
        right = mid - 1;
    }
}

printf("%.2f\n", ans / 100.0);
```

如果 `ans == 0`，输出自然就是 `0.00`。

### 5. 对应知识点

-   二分答案：求最大的可行电缆长度。
-   整数化：把米换算成厘米，避免浮点误差。
-   贪心计数：每根电缆尽可能切出指定长度的段，计算总数。
-   整数除法：`len[i] / mid` 表示能切出的完整段数，小数部分不能算一段。

### 6. 识别技巧

看到"分成相同长度""每段越长越好""至少需要 K
段"，可以尝试二分长度，并计算每个长度能切出多少段。

与穿梭星球题比较：

-   穿梭星球：判断一个距离是否需要移走不超过 M 个点。
-   电缆分割：判断一个长度是否能切出至少 K 段。

两道题都是"二分答案"，只是可行性判断不同。

## 四、赌徒下注：排序 + 枚举 + 双指针

### 1. 题目在问什么？

给出 N 个互不相同的整数。若某个数 d 等于另外三个不同赌徒的下注之和，就称
d 是获胜者。若有多个获胜者，输出最大的 d；没有则输出 `no solution`。

注意：组成和的三个数，以及目标数 d，必须来自四个不同的人。

### 2. 解题思路

先排序，从大到小枚举目标值 d，因为我们想找最大的获胜值。

固定目标值 d，再枚举其中一个加数 c。剩下需要找两个数 a、b，使：

``` text
a + b = d - c
```

由于数组已经排序，可以用双指针寻找 a 和 b：

-   `a` 从较小的数开始。
-   `b` 从较大的数开始。
-   如果 `a + b` 太小，增大 a。
-   如果 `a + b` 太大，减小 b。
-   相等时，检查四个下标是否互不相同。

### 3. 关键代码框架

``` c
qsort(a, n, sizeof(int), cmp);

/* 从最大的目标值开始 */
for (int d = n - 1; d >= 0; d--)
{
    int found = 0;

    for (int c = n - 1; c >= 0 && !found; c--)
    {
        if (c == d)
            continue;

        int i = 0;
        int j = n - 1;
        int target = a[d] - a[c];

        while (i < j)
        {
            if (i == c || i == d)
            {
                i++;
                continue;
            }

            if (j == c || j == d)
            {
                j--;
                continue;
            }

            long long sum = (long long)a[i] + a[j];

            if (sum == target)
            {
                found = 1;
                break;
            }
            else if (sum < target)
                i++;
            else
                j--;
        }
    }

    if (found)
    {
        printf("%d\n", a[d]);
        break;
    }
}
```

上面是核心思路框架。实际提交时，要在每组数据中初始化结果标记，并在整个
`d` 循环结束后，如果没有找到答案就输出 `no solution`。

### 4. 为什么要从大到小枚举 d？

因为题目要求输出最大的获胜值。

如果先检查最大的
d，并且确认它能由另外三个不同的数相加得到，那么它就是答案，可以停止搜索，不必再检查更小的目标值。

### 5. 对应知识点

-   排序：方便从大到小枚举目标值，并使用双指针。
-   枚举：固定目标值 d 和一个加数 c。
-   双指针：在有序数组中寻找两个数之和。
-   下标去重：四个数必须来自四个不同的人。
-   `long long`：加法时使用更宽的整数类型，避免潜在溢出。

### 6. 识别技巧

看到"某个数等于其他几个数之和"，可以先固定目标值，再把问题转成两数之和或三数之和。

注意：双指针的前提是数组已经排序。并且不能只比较数值，还要保证使用的是不同下标。

## 六、遇到类似题目时，按这个顺序思考

### 第一步：先找题目要最大化或最小化什么

-   "最大距离""最长长度""最小值尽可能大"：考虑二分答案。
-   "有多少种图形"：考虑枚举和计数。
-   "某个数等于几个数之和"：考虑排序、枚举、双指针。

### 第二步：想清楚怎样判断

二分答案题必须回答：

> 如果我猜答案是 x，怎么快速判断 x 可不可行？

如果答案越大越难满足，通常是： - 可行：尝试更大。 - 不可行：尝试更小。

### 第三步：看能否利用排序

排序经常能带来以下好处：

-   让双指针成立。
-   让二分查找成立。
-   方便从最大候选值开始搜索。

### 第四步：检查边界和重复计算

写完代码后检查：

-   是否有多组输入？是否要循环读入？
-   是否需要特殊处理没有答案的情况？
-   是否会重复计数？
-   是否会使用同一个元素多次？
-   是否可能出现整数溢出？
-   输出格式是否要求保留两位小数？

## 七、建议记住的代码模板

### 二分答案模板

``` c
int left = 最小可能值;
int right = 最大可能值;
int ans = 0;

while (left <= right)
{
    int mid = left + (right - left) / 2;

    if (mid 可行)
    {
        ans = mid;
        left = mid + 1;  // 求最大可行值
    }
    else
    {
        right = mid - 1;
    }
}
```

如果题目要求"最小可行值"，可行时通常应该缩小右边界，而不是扩大左边界。

### 双指针模板

``` c
int left = 0;
int right = n - 1;

while (left < right)
{
    int sum = a[left] + a[right];

    if (sum == target)
    {
        /* 找到 */
        break;
    }
    else if (sum < target)
        left++;
    else
        right--;
}
```

双指针通常要求数组有序，并且具体题目可能需要额外检查下标是否重复。

## 八、最后总结

这四道题最值得掌握的不是具体题目，而是四种思考方式：

1.  二分答案：不断猜答案，缩小范围。
2.  贪心判断：用简单规则快速检查猜测值是否可行。
3.  几何枚举：根据已知点计算其他点，再判断是否存在。
4.  排序与双指针：把多重枚举转化成更高效的查找。

练习新题时，可以先不写代码，先用一句话说清楚"我要枚举什么"和"怎么判断符合条件"。这两点想清楚后，再把它们翻译成循环和
`if-else`，会容易很多。
